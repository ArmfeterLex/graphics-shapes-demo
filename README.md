# Graphics Shapes Demo

Демонстрационное приложение на C# Windows Forms для рисования графических примитивов.

## Функциональность

- Выбор фигуры из ListBox:
  - Линия
  - Прямоугольник (контур)
  - Прямоугольник (заливка)
  - Эллипс (контур)
  - Эллипс (заливка)
  - Сектор (контур)
  - Сектор (заливка)
- Автоматическая отрисовка при выборе пункта
- Очистка области перед новой отрисовкой
- Красное перо толщиной 4px, зеленая заливка

## Интерфейс

- listBox1 — список доступных фигур
- Область формы — поле для рисования

## Примеры отрисовки

При выборе пункта:
- Линия — рисуется линия от (150,40) до (350,180)
- Прямоугольник — контур или заливка размером 250×150
- Эллипс — вписанный в тот же прямоугольник
- Сектора — с разными углами

## Куда можно встроить

- В графические редакторы
- В обучающие приложения по GDI+
- В демонстрацию работы с Graphics
- В примеры рисования примитивов

## Требования

- Windows
- .NET Framework / .NET Core с WinForms

## Примечание

Рисование происходит непосредственно на форме. При перекрытии окна рисунок исчезает — для сохранения нужно переопределить OnPaint или использовать PictureBox.
